Pip's Little Dream Desktop

A whimsical, interactive website inspired by dreamy pixel art, nostalgic desktop experiences, and soft pastel aesthetics.

About the Project

Pip's Little Dream Desktop is a creative web experience built for the haX.baby hackathon. It brings together visual storytelling, interactive elements, and a cozy dream-inspired design in one place.

The website is designed to feel like a small digital world where visitors can explore projects, discover stories, and leave messages.

Features

- Home: An introduction to Pip's dreamy world.
- About: The inspiration and concept behind the project.
- Projects: A collection of creative projects displayed in a playful card layout.
- Story: Interactive chapters that visitors can explore.
- Guestbook: A space for visitors to leave messages.
- Visual Design: Soft pastel colors, pixel-art-inspired elements, clouds, stars, and a cohesive layout.
- Responsive Layout: Designed to provide a pleasant experience across different screen sizes.
